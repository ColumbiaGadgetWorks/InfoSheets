## Safety First ⚠️
- **Always wear safety glasses**
- **Never leave the laser unattended while operating**
- **Ensure proper ventilation is active**
- **Keep fire extinguisher nearby**
- **No reflective materials (mirrors, metal)**

## Startup Procedure
1. Turn on ventilation system
2. Power on laser cutter main switch
3. Initialize software and home the laser
4. Load material and focus laser
5. Run test cut on scrap material

## Shutdown Procedure
1. Remove all materials from bed
2. Clean lens and mirrors if needed
3. Power down laser system
4. Turn off ventilation (after 5-minute cooldown)
5. Log usage in maintenance sheet
